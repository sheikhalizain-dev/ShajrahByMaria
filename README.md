# Shajra by Maria

Multi-page static website (HTML, CSS, JavaScript). No build step.

| Page | File |
|---|---|
| Home | `index.html` |
| Shop (all products) | `shop.html` |
| Product pages | `products/<name>.html` (aaks, baft, rivayaat, naqsh, chilman, bisaat, kargha) |
| About | `about.html` |
| Craft (loom, cloth, crossword) | `craft.html` |
| Contact / how to order | `contact.html` |

- `css/style.css` styles for every page
- `js/common.js` menu and cloth animation (every page); the other files in `js/` each belong to one feature
- `img/` logo and photographs, product photos in `img/p/`

Open `index.html` in a browser, or host the folder on GitHub Pages, Cloudflare Pages or Netlify. All links are relative, so it also works in a sub-folder.
